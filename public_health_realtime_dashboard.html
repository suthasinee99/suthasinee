ตั้งค่าการเชื่อมต่อ Google Sheets

กำหนด ลิ้งก์ Google Sheet CSV หรือเปลี่ยนคอลัมน์สำหรับการซิงค์ข้อมูล

* ระบบสกัด CSV จาก Google Sheets Pubhtml ลิ้งก์ของคุณโดยอัตโนมัติแล้ว

โหมดทดสอบข้อมูล (Demo Mode):

ใช้ข้อมูลสาธิตตัวอย่างหากยังไม่ได้เผยแพร่ Google Sheet หรือเกิดปัญหา CORS

ขั้นตอนการเปิดใช้งานขึ้น GitHub Pages (ฟรี 100%)

คุณสามารถเผยแพร่เว็บแดชบอร์ดนี้ให้เพื่อนร่วมงานและผู้บริหารดูออนไลน์ได้ทันที

1

บันทึกไฟล์นี้เป็น `index.html`

คัดลอกโค้ดทั้งหมดในหน้านี้แล้วตั้งชื่อไฟล์ว่า index.html

2

สร้าง Repository บน GitHub

เข้าไปที่ github.com/new ตั้งชื่อ เช่น health-dashboard และเลือกเป็น Public

3

อัปโหลดไฟล์ `index.html`

กดที่ "uploading an existing file" แล้วลากไฟล์ `index.html` วาง จากนั้นกด **Commit changes**

4

เปิดใช้งาน GitHub Pages

ไปที่เมนู **Settings** > **Pages** ในหัวข้อ Source ให้เลือก branch main แล้วกด **Save**
